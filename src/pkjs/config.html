Custom complications

Shows a value from any JSON API. Create one, then pick it in a corner or the center.

How to use
  • Up to 8. The phone makes the requests, so the watch needs a connection to it.
  • Plain GET only, no headers: an API key has to go in the URL.
  • Title names it here. Header is what the face shows with the value: up to 4 characters, fixed or a {{pattern}}.
  • Text shows up to 20 characters: letters, digits, spaces and % , - . / : only. In a corner a long one shrinks to fit. Numbers are rounded to 2 decimals.
  • Bar and gauge place the first {{value}} in Text between min and max, in the accent color.
  • A bar's value shrinks to leave half the corner to the bar.
  • A gauge in the center hides min and max longer than 3 characters.
  • If a refresh fails the last value stays. A value that can't be read shows as --.
